# PromptFence Agent Skills Index

This directory contains reusable, native AI coding skills for the PromptFence platform.

| Skill | Primary Focus | Trigger / Use When |
|---|---|---|
| [`project-architecture`](./project-architecture/SKILL.md) | Architectural integrity & boundaries | Adding new cross-cutting modules, verifying layer separation |
| [`frontend-engineering`](./frontend-engineering/SKILL.md) | Next.js 14 App Router, TypeScript, UI | Creating pages, forms, components, TanStack Query hooks |
| [`backend-engineering`](./backend-engineering/SKILL.md) | FastAPI, SQLAlchemy 2.0, Pydantic | Writing API endpoints, services, repositories, schemas |
| [`application-security`](./application-security/SKILL.md) | Auth, SSRF, IDOR, Token Rotation | Implementing security-sensitive endpoints, external HTTP calls |
| [`database-engineering`](./database-engineering/SKILL.md) | PostgreSQL, Alembic, Models | Designing tables, constraints, migrations, indexes |
| [`testing-and-quality`](./testing-and-quality/SKILL.md) | Pytest, Vitest, Playwright | Writing unit, integration, security, and E2E tests |
| [`code-review`](./code-review/SKILL.md) | Architectural & security review | Auditing PRs or code changes for anti-patterns |
| [`documentation-maintenance`](./documentation-maintenance/SKILL.md) | Technical docs, ADRs, API specs | Updating README, ADRs, database dictionaries, diagrams |
