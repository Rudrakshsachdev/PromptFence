# Database Migrations Guide — PromptFence

## Overview
PromptFence uses Alembic with async SQLAlchemy to manage PostgreSQL database migrations.

## Migration Files
- `backend/alembic.ini`: Primary configuration specifying database URL and migration scripts folder.
- `backend/migrations/env.py`: Async migration runner that inspects `Base.metadata` from `app.core.database`.
- `backend/migrations/versions/`: Directory containing sequential revision scripts.

## Migration Rules
1. **Never edit an applied migration**: If a schema fix is needed, generate a new migration revision.
2. **Reversible migrations**: Every revision must implement both `upgrade()` and `downgrade()`.
3. **Auto-generate review**: Always review autogenerated revisions for missing indexes and constraints.

## Developer Commands
```bash
# Apply all pending migrations to head
make migrate
# or: cd backend && alembic upgrade head

# Create a new autogenerated revision
make migration m="add_new_column"
# or: cd backend && alembic revision --autogenerate -m "add_new_column"

# Roll back the most recent migration
cd backend && alembic downgrade -1
```
